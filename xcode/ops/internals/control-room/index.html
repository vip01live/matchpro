PAGES Էջերի կառավարում

Այս բաժինը բեռնում է repository-ի առկա HTML էջերը։ Ընտրիր էջ, խմբագրիր տեքստերը և metadata-ն, ապա պահպանիր։ Iframe player-ները և admin/internal էջերը ցուցակից բացառված են։ Բարդ ինտերակտիվ բաղադրիչների կամ արտաքին iframe-ի ներսի բովանդակության համար կարող է պահանջվել առանձին խմբագրիչ։

NEW Ստեղծել բազմալեզու էջ

Ստեղծվելու է մեկ հիմնական URL և երեք իրական HTML էջ՝ հայերեն, ռուսերեն և անգլերեն տարբերակներով։ Յուրաքանչյուր լեզվային էջ կունենա իր H1-ը, title-ը, description-ը, canonical-ը և սոցիալական metadata-ն։

MEDIA Նկարներ և հղումներ

Կառավարիր առկա HTML էջում նկարների հասցեներն ու alt տեքստերը, ինչպես նաև հղումների URL-ները, վերնագրերը և բացման եղանակը։ Նոր ֆայլ չի վերբեռնվում, եթե հասցեն պարզապես փոխում ես։

LAYOUT Տարրերի տեսք և դասավորություն

Ընտրիր տարրի տեսանելիությունը, գույները, տառաչափը, բացատները և դիրքը հարակից տարրերի նկատմամբ։ Դատարկ դաշտերը պահպանում են stylesheet-ի գործող արժեքները։ Տեղափոխումն իրականացվում է միայն ընտրված տարրի համար՝ պահպանման պահին։

TEXT Էջի տեքստեր

Ստորև հայտնաբերվում են պարզ տեքստային տարրերը։ Փոխված տեքստը պահպանվում է նույն HTML տարրի մեջ։
