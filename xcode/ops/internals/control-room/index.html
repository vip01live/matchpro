GitHub-ի միացում՝ միայն առաջին կարգավորման համար

Այս CMS-ը պահպանում է փոփոխությունները GitHub-ում։ Առաջին անգամ կամ նոր բրաուզերում պետք է հաստատել GitHub կապը։ Token-ը կոդավորվում է այս բրաուզերում՝ ձեր գաղտնաբառով։

Սովորական մուտքի ժամանակ այս դաշտը պետք չէ լրացնել։ Ստեղծել GitHub token՝ միայն vip01live/matchpro ռեպոզիտորի համար, Contents: Read and write և Metadata: Read-only իրավունքներով։

GitHub Pages-ը ինքնուրույն չի ապահովում սերվերային login։ Backend-ը տեղակայելուց հետո մուտքը կատարվելու է օգտանունով և գաղտնաբառով՝ առանց GitHub token-ը բրաուզերում պահելու։
